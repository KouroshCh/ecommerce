# Ecommerce

Frontend foundation for an ecommerce application built with React, TypeScript,
Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Source structure

- `src/components`: reusable UI components
- `src/pages`: page-level components
- `src/data`: typed local data and fixtures
